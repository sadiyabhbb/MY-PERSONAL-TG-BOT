# Telegram Chatbot with OpenAI Integration

**এই বটটি তৈরি করা হয়েছে Node.js এবং Telegraf লাইব্রেরি ব্যবহার করে, যেখানে OpenAI GPT API ইন্টিগ্রেশন রয়েছে। বটটি কাস্টম কমান্ড সাপোর্ট করে এবং খুব সহজেই কাস্টমাইজ করা যায়।**

---

## ফিচারসমূহ

- Telegram বট হিসেবে কাজ করে  
- OpenAI GPT API ব্যবহার করে AI চ্যাট  
- কাস্টম কমান্ড যোগ এবং মুছে ফেলার সুবিধা  
- অ্যাডমিন, ওয়াইটলিস্ট, ব্ল্যাকলিস্ট সাপোর্ট  
- MarkdownV2 এবং HTML ফরম্যাটিং হেল্পার  
- লগিং এবং মেসেজ কনসোল প্রিন্ট  
- ওয়েব ড্যাশবোর্ড (public/index.html)

---

## প্রয়োজনীয়তা

- Node.js v18 বা তার পরের ভার্সন  
- Telegram বট টোকেন  
- OpenAI API Key  
- `.env` ফাইল যেখানে কনফিগ থাকবে
